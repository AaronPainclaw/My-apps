# Архив Инквизиции Ордо Еретикус — версия 2.0

В каталоге размещены готовая переносимая сборка для Windows x64 и полный архив исходного кода.

## Файлы

- `Ordo-Hereticus-Archive-2.0.0-Windows-x64.zip` — переносимая версия с EXE, инструкцией и данными доступа.
- `Ordo-Hereticus-Archive-2.0.0-Source.zip` — полный исходный проект без `node_modules` и промежуточных сборок.

Версия 2.0 сохраняет систему прав, ридер, редактор, медиаплеер, «Очищающую литанию Омниссии» и фундамент GitHub-синхронизации. В оболочку добавлены CRT-анимация запуска, почти монохромное оформление, аквилы и знаки Инквизиции, а также синтезируемые звуки аналогового терминала и низкий машинный гул.
