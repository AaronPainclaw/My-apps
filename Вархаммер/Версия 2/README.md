# Архив Инквизиции Ордо Еретикус — версия 2.0

Здесь размещены переносимая Windows x64-сборка и полный архив исходного кода версии 2.0.

## Исходники

`Ordo-Hereticus-Archive-2.0.0-Source.zip` — полный исходный проект без `node_modules` и промежуточных сборок.

## Переносимая версия

Из-за ограничения канала загрузки Windows-архив сохранён четырьмя побайтными частями в каталоге `Portable.parts`. Содержимое не перекодировано и не изменено.

1. Скачайте весь каталог `Версия 2`, сохранив подпапку `Portable.parts`.
2. Запустите `Собрать переносимую версию.cmd`.
3. Скрипт создаст рядом файл `Ordo-Hereticus-Archive-2.0.0-Windows-x64.zip` и автоматически проверит SHA-256.
4. Распакуйте полученный ZIP и запускайте переносимый EXE из него.

Версия 2.0 сохраняет систему прав, ридер, редактор, медиаплеер, «Очищающую литанию Омниссии» и фундамент GitHub-синхронизации. В оболочку добавлены CRT-анимация запуска, почти монохромное оформление, аквилы и знаки Инквизиции, а также синтезируемые звуки аналогового терминала и низкий машинный гул.
